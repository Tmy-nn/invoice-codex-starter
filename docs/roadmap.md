# 業務への拡張例

請求書以外の業務は、各社の業務とデータ取扱条件に合わせて選びます。下表は実装予定の約束や導入順ではありません。

| 業務例 | 最初の入力・出力 | 人が残す判断 |
|---|---|---|
| 請求書 | Excelから検証表・PDF・EMLを生成 | 金額、宛先、様式、送信 |
| 勤怠 | タイムカード画像から確認用の転記表を作る | 原本照合、修正、給与確定 |
| ニュースレター | 指定した一次サイトのURL・取得日・要約案を一覧化 | 文面確定、送信 |
| 公的支援制度の調査 | 公式情報の対象条件・期限・出典を整理 | 自社や取引先への適用判断 |
| ファイル整理 | 移動候補と復元表をプレビュー | 移動の承認。削除はしない |
| AIエージェント分担 | 業務ごとの入力・出力・権限・ログを明文化 | 権限付与と最終判断 |

このリポジトリで実装済みなのは請求書の架空データ実演のみ。ほかの行は設計候補であり、動作機能ではありません。
