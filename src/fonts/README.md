# Bundled Japanese font

`MPLUS1p-Regular.ttf` is the unmodified regular-weight font downloaded from the official Google Fonts repository:

- Font: https://github.com/google/fonts/blob/main/ofl/mplus1p/MPLUS1p-Regular.ttf
- License and copyright notice: https://github.com/google/fonts/blob/main/ofl/mplus1p/OFL.txt
- Local license copy: `MPLUS1p-OFL.txt`
- Font name used by PDF generator: `MPLUS1p` (M PLUS 1p Regular TrueType)
- SHA-256: `2F294AD496432B1608F070D310E3AA2ADCF1DE4AF429F4901DF97EC4BD361ED1`

The font remains under the SIL Open Font License 1.1. It is bundled so Japanese invoice PDFs embed their glyphs on Windows and macOS.
